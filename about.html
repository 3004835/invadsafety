About InvadSafety

InvadSafety helps schools, parents, and IT teams understand how a single URL lands in different web filtering ecosystems. Instead of guessing whether a link is "safe," you can see how major filtering vendors would categorize it — in one place.

What the checker does

You paste a URL. InvadSafety normalizes it to a domain and looks it up. Rows marked Live come from a real DNSFilter domain lookup API call. Every other row is simulated: we map the known category onto that vendor's naming scheme, then mark it allowed or blocked using a simple school-policy rule set.

Why simulated results are labeled

Most filtering vendors do not publish a public "what category is this URL" API. Their lookup tools live inside admin consoles or firewall CLIs. Rather than pretend we can query them all, we show what a plausible result would look like and tell you it's simulated. Transparency matters more than a long list of fake checkmarks.

What we don't do

  • We don't store the URLs you check.
  • We don't call a vendor's API without disclosure.
  • We don't claim simulated results are authoritative.

Who it's for

District IT administrators comparing filter behavior, teachers checking a resource before assigning it, and parents who want a second opinion on a link.
