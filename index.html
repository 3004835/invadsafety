    How to read this: Rows marked Live come from a real API query. Rows marked Simulated are generated by mapping a category to each vendor's taxonomy. They do not reflect a real-time query of that vendor's system.

    🔍 One link, many filters

    Schools run different filtering vendors. InvadSafety shows how the same URL lands in each ecosystem, so you can spot mismatches before they affect students.

    🛢️ Live DNSFilter lookup

    DNSFilter exposes a public domain lookup API. When configured, InvadSafety calls it directly and shows the returned category.

    🧭 Transparent by design

    Simulated rows are always labeled. No vendor API is called without your knowledge, and no data is stored on our servers.
